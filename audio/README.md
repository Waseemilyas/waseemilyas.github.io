# Prayer-time audio files

The prayer-time audio files in this directory (`adhan.mp3`, `iftar.mp3`, and `sehri.mp3`) are intentional. They feed a Home Assistant automation run by Waseem.

- They are fetched by a Home Assistant automation over HTTP.
- They are deliberately unlinked from the portfolio site.
- They must remain in this repository and must not be removed or renamed.
